# Build in Public

## Voice
Plain, evidence-first, a little dry. Numbers and Solscan links over adjectives. No price talk about $PWIRE, no "moon", no "gem". Tag @clawpumptech on milestones.

## Daily post (one per day, Sep 30 → Oct 7)
Format: `Day N: <what shipped>` + 1 screenshot/clip + 1 number + link to /live.
- Sep 30: indexing every pump.fun launch (launches/min)
- Oct 1: rug-risk v0 + backtest precision
- Oct 2: agents can now pay for rug checks (devnet video)
- Oct 3: **mainnet live**: first paid calls (Solscan links)
- Oct 4: pay in $ANSEM
- Oct 5: early-buyer cluster maps + "caught it" examples
- Oct 6: open-source starter; "integrate in 2 minutes"
- Oct 7: recap thread with /live stats (first-party vs third-party)

## "Caught it" clip rules
Only tokens scored HIGH/EXTREME **before** the dump, with timestamps for both. Refer to wallets, not people. Say "risk". Never mock buyers.

## Outreach (builders onboarded)
DM 20 agent builders (ClawPump agents, Solana agent devs): one line of value, the install snippet, and an offer to pair for 10 min. Log in `OUTREACH.md`.

## Stream prep (15 min, 4 questions)
Founder/team → product + live demo (USDC then $ANSEM) → market/GTM/traction (from /live) → $PWIRE utility + roadmap. Rehearse once; keep a recorded fallback demo.

## Approval
Every draft goes to Mises. Nothing is published by an agent.
