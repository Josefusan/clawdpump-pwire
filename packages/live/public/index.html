How it works

One HTTP call. One cent. One settled transaction.

01 · ASK

Agent requests a score

GET /v1/risk/<mint> for any pump.fun launch PumpWire has seen.

02 · 402

PumpWire names the price

HTTP 402 with an x402 offer: $0.01 USDC on Solana ($0.005 for $PWIRE holders).

03 · PAY

Agent signs from its wallet

A USDC transfer bound to this exact request by a memo. The facilitator pays the SOL fee.

04 · SCORE

Score + reasons, settled

0–100, LOW to EXTREME, with the evidence: deployer history, bundles, holder concentration.

        For agents and builders

        Give your agent its own wallet. It pays per call.

        MCP: add @pumpwire/mcp to Claude, Cursor or any MCP client. It exposes rug_risk_score(mint) and pays from your agent's wallet, with a daily cap.

        {
  "mcpServers": {
    "pumpwire": {
      "command": "node",
      "args": ["/PATH/TO/clawdpump-pwire/packages/mcp/dist/index.js"],
      "env": {
        "PUMPWIRE_API_URL": https://…,
        "SOLANA_KEYPAIR_PATH": "/PATH/TO/agent-wallet.json",
        "PUMPWIRE_NETWORK": "mainnet",
        "PUMPWIRE_DAILY_CAP_USD": "1"
      }
    }
  }
}

        Raw HTTP: any x402 client works.

        curl -i https://…/v1/risk/<mint>
HTTP/1.1 402 Payment Required   # x402 offer: 10000 USDC base units
